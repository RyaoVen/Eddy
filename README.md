# Eddy

Eddy 是支持本地与企业服务器工作区的 AI 办公应用。这里提供用户文档和测试版下载；应用源码维护在 GitCode。

[使用文档](docs/index.md) · [测试版本下载](https://github.com/RyaoVen/Eddy/releases) · [问题反馈](https://github.com/RyaoVen/Eddy/issues)

测试版本：**0.1.0-beta.1**。四种桌面安装包与 Linux 双架构镜像分别记录构建和运行验收，只有验收完成的版本才会从 Draft 发布为 Pre-release。

支持 macOS 14+、Windows 11 的 x86_64/ARM64，以及 Linux AMD64/ARM64 Docker 部署。完整桌面包包含 Python、LibreOffice 和中文字体；真实模型需要自行配置服务与密钥。
